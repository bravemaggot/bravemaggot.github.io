3. **Мини-терминалы** в карточках демо — это пример формата вывода, а не реальные скриншоты. Заменить на реальные скриншоты, когда боты доедут.
4. **Отзывы / кейсы** — на странице их нет: нет подтверждённых результатов, которые можно было бы показать без выдумки. Добавлять по мере появления реальных.
